Problem types

Errors are RFC 9457 problem documents. Plain HTTP errors use about:blank; the domain errors below have their own type. The full API reference is at /docs.

validation-failed 422
One or more attributes are invalid. errors lists each one with a JSON pointer, for example #/title.
serial-number-taken 409
The serial number belongs to a different book. Repeating an add with identical attributes answers 200 instead.
book-withdrawn 409
The book was withdrawn from the catalog. Lending it, or adding a book with its serial number, answers 409; the serial number is never given to another book.
book-borrowed 409
The book is borrowed, so it cannot be withdrawn until it is returned.
book-already-borrowed 409
Another reader has the book. The same reader repeating the borrow gets 200 with the existing borrowing.
card-number-taken 409
The card number belongs to a reader with different details.
email-taken 409
The email belongs to a different reader.
