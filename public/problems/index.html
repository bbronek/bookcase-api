Problem types

Errors are RFC 9457 problem documents. Plain HTTP errors use about:blank; the domain errors below have their own type. The full API reference is at /docs.

validation-failed 422
One or more attributes are invalid. errors lists each one with a JSON pointer, for example #/title.
serial-number-taken 409
The serial number is already registered, even if the attributes match or the book is withdrawn.
book-withdrawn 409
The book was withdrawn from the catalog and cannot be lent. Its history remains readable.
book-borrowed 409
The book is borrowed, so it cannot be withdrawn until it is returned.
book-already-borrowed 409
The book is already borrowed. Repeating the request for the same reader also answers 409.
card-number-taken 409
The card number is already registered, even if the reader's details match.
email-taken 409
The email is already registered.
